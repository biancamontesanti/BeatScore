# Beat Score Build Export

Blender-ready reconstruction of the static venue generated by `src/dancefloor.ts`.

- `BeatScore_Build.blend`: native editable Blender scene with named collections.
- `BeatScore_Build.glb`: self-contained glTF binary.
- `BeatScore_Build.gltf`: editable glTF package; keep it beside `BeatScore_Build.bin` and `beatscore.png`.

The venue is centered at the Blender origin, converted from Decentraland Y-up coordinates to Blender Z-up coordinates, and uses meters. Runtime UI, avatars, leaderboard data, reactive floor animation, and other game logic are intentionally excluded from this static modeling export.

Regenerate the package with:

```sh
"/Applications/Blender 5.1.app/Contents/MacOS/Blender" --background --python tools/export_build_to_gltf.py
```
